03 协议栈与报文结构

3.1 报文格式

##<数据段长度4位><数据段><CRC16 4位>

数据段 = QN=…;ST=…;CN=…;PW=…;MN=…;Flag=…;PN=…;CP=&&数据区&&

示例（分钟数据上报，示意）：
##0384QN=20261104141700001;ST=32;CN=2051;PW=123456;
MN=FHZY-S-01DTU01;Flag=4;PN=2011;
CP=&&DataTime=20261104141700;a21026-Rtd=33.215,a21026-Flag=N;
a00000-Rtd=42.650,a00000-Flag=N;...&&A1B2
要素规则实现要点
起始符##粘包扫描锚点
长度4 位十进制，指数据段字节数用于半包判定，必须按字节而非字符
CRCCRC16（Modbus 多项式），大端，4 位大写十六进制校验失败按错误应答返回，不入库
分隔字段间 ;，数据区 && 包裹，参数间 ,解析器不得依赖字段顺序
编码ASCII（中文按 GBK 或 UTF-8 由 PN 声明）统一按 UTF-8 解码失败回退 GBK

3.2 关键字段

字段含义用途
QN请求编号（时间戳+序列）幂等键：同一 QN 重复上报去重
ST系统编码区分行业/系统类型
CN命令编码决定解析分支
PW访问密码设备接入鉴权（第一道）
MN设备/站点唯一编号映射 station_code + dtu_sn
Flag包标志（是否含数据段、是否加密等）解密判定依据
PN协议版本号2017 / 2025 分流
CP指令参数区业务数据主体

05 通信安全：SM4 与密钥管理

5.1 加密要求

项要求
算法国密 SM4，128 位密钥，ECB 模式，No Padding（按块对齐补位）
加密范围数据上传类命令（约 2000~2999）、密钥管理（1014）、现场机信息（3020）；其余命令可明文（以正文为准）
传输通道互联网必须加密；专网宜加密
密钥有效期最长 90 天，到期前由数采仪自动向上位机获取新密钥
密钥保管不得以任何明文形式传输、显示、存储；平台侧加密存储于 KMS/密钥表
失效处理密钥丢失或过期需由排污单位在上位机重置，平台须提供重置流程

5.2 密钥状态机与告警

初始密钥（出厂/注册下发）
      │ 首次联网
      ▼
   ACTIVE ──每 90 天（到期前自动更新）──▶ ACTIVE（版本 +1）
      │
      ├─ 更新失败 ──▶ EXPIRING（进入告警倒计时 7/3/1 天）
      │                    │
      │                    └─ 到期 ──▶ EXPIRED（数据无法解密，整站中断）
      ▼
   RESET（排污单位在上位机重置 → 重新下发）
告警级别触发条件动作
密钥 7 天内到期P2expire_at - now ≤ 7d飞书通知运维主管，提示现场检查
密钥更新失败P1fail_count ≥ 2飞书 + 短信，派工单
密钥已过期P1解密失败且 expire_at < now立即告警 + 引导重置流程

06 设备身份与联网确认

6.1 三步流程

步骤执行方动作系统状态
① 注册设备厂商在上级平台注册产品型号、硬件信息、初始密钥REGISTERED
② 激活数采仪上传 SN、CPUID、MAC，与注册信息比对一致后获取传输密钥ACTIVATED
③ 确认排污单位按排污许可证信息核对联网内容并确认CONFIRMED
红线

确认前的数据为无效数据。系统必须在原始数据页对该类数据单独标记「未确认」，不得计入有效数据率，也不得用于超标判定——否则一旦被监管抽查，整套统计都要推翻。

6.2 SN 校验规则

校验项规则不一致处理
SN 与台账上报 SN = 台账登记 SNP1 报警「疑似更换/翻新机」，数据标记为待核
上报频次每日 0:05 前上报一次超时未上报 → P2「SN 未上报」
更换时效更换设备后 5 分钟内上报新 SN超时 → P1，并要求补录更换工单
SN 结构厂商识别码 + 产品类别 + 校验位 + 序列号格式非法 → 拒绝入库并记录原始报文

07 双维度数据标记

7.1 设备标记（dev_flag）

代码含义说明
N数据有效默认标记
D故障设备故障、检修、断电导致的缺失或无效
C校准校准、核查期间
M日常维护计划性维护保养期间
T超量程超过当前工作量程
Td关键工况参数故障反映生产工况的关键参数（炉温、蒸发量等）故障

优先级（时间相同时从高到低）：D > C > M > T > Td；存在多个维护类标记时，优先取持续时间最长的标记。

判定主体：由现场端根据仪器状态与运行参数自动判定并随数据同步上传，不应人工干预。系统若发现"人工改标记"的痕迹（如标记突变而无对应设备状态），视为异常。

7.2 生产工况标记（prod_flag）

代码含义说明
N正常运行正常排放时段
St启动开始启动至稳定运行前
Stc冷启动（冷点火）完全停止状态下启动
Sth热启动（热点火）低负荷/未完全停止状态下启动
Sd停炉（机）由正常运行转为停止运行的过程
B闷炉炉膛密闭自然降温/保温
F停运完全停止运行至再次启动前
—停排 （水污染源）废水排放单位特有，编码以正文为准
业务含义

工况标记是非正常工况超标判定的依据：标记为启动/停炉/停运时段的超标，可按规则不计入超标次数（具体是否豁免由地方监管口径决定，系统做成可配置，不要写死）。

08 附录 G 有效性判定

层级判定规则系统实现
分钟值采集成功且标记为 N 即为有效quality 字段：1 有效 / 2 无效 / 3 未标记
小时值该小时有效分钟数 ≥ 45，小时值才有效定时任务整点后 5 分钟计算，写入 ts_data_hour
日均值该日有效小时数 ≥ 75%（18 小时），日均值才有效次日 00:30 计算
停运时段站房停运期间数据不参与统计按 ops/station 停运区间剔除
超量程超上限时以量程上限值参与统计，同时打 T 标记计算前置处理
无有效数据统计时段内无有效数据时，全部无效数据参与计算降级策略，需在报表备注中说明
负值修约SO₂ 标干浓度 > -15 mg/m³ 时修正为 0.5 mg/m³规则可配置，按因子维护
禁止数据保持不得设置数据保持、零值、固定值等干预输出恒值检测：连续 N 条完全相等 → 疑似保持，告警

10 接入网关实现

10.1 处理流水线

TCP 连接
  └─ IdleStateHandler（读空闲 300s 断链）
      └─ LengthFieldBasedFrameDecoder（按 ## + 4 位长度拆包）
          └─ Crc16Validator（校验失败 → 错误应答 + 丢弃）
              └─ Sm4DecryptHandler（按 Flag/CN 判定是否解密）
                  └─ MessageParser（按 CN 分流为强类型对象）
                      └─ IdempotentFilter（QN + MN 去重，Redis SETNX TTL 24h）
                          └─ AckWriter（立即回 9011/9012 应答，先应答后落库）
                              └─ MQ Producer（topic: hj212.{CN}）
                                  └─ 消费端：入库 / 计算 / 规则引擎 / 推送

10.2 关键实现约束

约束做法原因
先应答后落库解析成功后立即回应答，再异步落库现场机超时重发会造成大量重复
幂等QN+MN 做唯一键，Redis SETNX + DB 唯一索引双保险补传与重发必然重复
半包/粘包按声明长度截取，不足则等待，超长则丢弃并告警NB-IoT/4G 网络下极常见
解码容错UTF-8 失败回退 GBK；数值非法置 NULL 并计数老旧设备编码不规范
背压MQ 积压超阈值时降级为直接落盘队列峰值 3 倍突发
时钟偏差记录 DataTime 与服务器时间差，>60s 告警时间错会导致数据落到错误时段
原始报文留存加密报文原样存 7 天（对象存储/日志）争议时唯一证据

10.3 连接管理

项参数
监听TCP 20000（可配置）；HTTP 20001
最大连接5000（单节点），可水平扩容
鉴权PW + MN 白名单；未注册 MN 直接拒绝并记录
心跳读空闲 300s 视为离线；离线即刻更新联网状态并发告警
下行通道按 MN 查找 Channel，找不到则入待发队列，设备上线后补发

11 异常场景处理

场景表现处理策略
CRC 校验失败报文内容不可信回错误应答（CRC 错误码），不入库，计数告警
解密失败密钥不匹配/过期隔离到 pending 表，触发密钥告警，不污染主数据
MN 未注册野设备接入拒绝，记审计，P1「非法设备接入」
时间戳超前/滞后现场机时钟漂移按 DataTime 入库，同时记录偏差；>1h 拒绝并告警
补传乱序历史数据晚到允许乱序写入；小时/日汇总按区间重算（幂等覆盖）
数据重复重发/补传重叠QN 去重 + 唯一索引；重复报文只更新最后一次
长连接抖动4G 弱网频繁断连指数退避重连；离线时长计入有效传输率
突发洪峰断网恢复集中补传限流（按 MN 令牌桶），保序处理，防止打爆数据库
