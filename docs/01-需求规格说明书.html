01 项目背景与建设目标

1.1 背景

排污单位污染源自动监控设施普遍委托第三方运维。监管方长期面临三个问题：运维是否到位无法验证、监测数据真假难辨、运维台账靠纸质难追溯。HJ 212—2025 于 2026-01-01 实施、HJ 212—2017 同步废止，把监管视角从"看几个浓度值"推到"看设备身份、工作参数、原始信号、数据标记、操作日志"，为"穿透式监管"提供了数据基础。

本系统要解决的正是这个缝隙：把标准的传输要求，落成一条可自证、可核查、可追责的运维证据链。

1.2 建设目标

编号目标可量化验收口径
G1数据接得全、接得准支持 HJ 212—2025 全量报文接收，含监测数据、工作参数、设备状态、操作日志、原始信号；报文解析成功率 ≥ 99.9%
G2运维干得实、留得下痕每一次巡检/校准/维修均可回溯到人、时间、位置、照片、耗材与设备参数变更
G3异常报得早、处置闭环P1 报警从产生到触达 ≤ 60 秒；报警处置闭环率可统计
G4考核算得清、对得上有效数据率、超标次数、到位率口径与附录 G 一致，与省/国发平台差异可解释
G5多端可用Web 管理端 + 微信小程序 + 飞书 + 公众号，四端消息与权限一致

权限设计要点

① 权限 = 功能权限（菜单/按钮）× 数据权限（租户 → 组织 → 区域 → 站房），两者必须同时校验，不能只在前端隐藏菜单。

② 所有业务查询走统一数据权限拦截器，禁止在 SQL 里手写条件——否则一处漏写就是越权。

③ 企业用户与监管用户是只读 + 流程参与角色，不得直接修改运维记录，只能"确认/退回"，修改必须由运维方发起，留痕。

04 业务主线：运维证据链

本系统的设计主轴不是"功能多"，而是六个环节必须能互相印证。任何一环断掉，甲方就有理由质疑运维真实性。

#环节载体要证明的事交叉校验
1该做的运维计划（月历四态）应做尽做，"未计划"即缺口计划覆盖率 = 已排期站房 / 应运维站房
2派了人任务单 + 指派人有明确责任人任务必须来自计划，禁止"计划外任务"绕过
3到场了电子围栏打卡 + 车辆轨迹 + 照片水印人确实到了现场打卡点与站房坐标距离 ≤ 300 m
4真干了运维记录 + 物资消耗 + 参数变更试剂真换了、参数真调了更换记录 ⇄ 出库单 ⇄ 参数变更时间
5设备状态数据标记（N/D/C/M/T/Td）当时设备处于什么状态标记 ⇄ 运维记录：标了 M 必须有维护单
6有人负责审核 + 审计日志每一环都可追到人审核人 ≠ 执行人；审计日志只追加
核心差异化功能：标记 ⇄ 工单 双向核验

正向校验：数据标记为 C/M/D/Td 的时段，系统必须找到同站房、时间重叠的对应类型运维记录；找不到 → 产生「疑似虚假标记」预警。

反向校验：运维记录做了校准（C），但对应时段的数据标记不是 C（仍为 N）→ 产生「漏标」预警，直接影响有效数据率与考核。

这一条是参考平台没有的，也是监管方最想要的能力，建议作为投标/汇报的第一亮点。

06 关键业务规则

编号规则定义
BR-01计划覆盖率= 本月已排期站房数 ÷ 本月应运维站房数。应运维站房 = 状态为"正常/异常"且合同在有效期内的站房
BR-02计划外任务故障类任务允许计划外创建，但必须关联报警或故障上报；其他类型禁止
BR-03到场判定打卡点与站房坐标距离 ≤ 300 m 且人脸比对通过，才计为"到场"；否则标记"异地打卡"
BR-04审核不相容审核人不得为执行人；同一记录被驳回 ≥3 次自动升级至运维单位管理员
BR-05标记核验数据标记 C/M/D/Td 的时段，必须存在时间重叠的对应运维记录，否则生成"疑似虚假标记"
BR-06漏标核验存在校准记录但对应时段标记为 N，生成"漏标"；校准前后各 30 分钟为必标窗口
BR-07小时数据有效该小时内有效分钟数据 ≥ 45 个，该小时值才有效（附录 G）
BR-08日数据有效该日有效小时数 ≥ 75%（18 小时），日均值才有效（附录 G）
BR-09停运不计站房处于"停运"状态期间的数据不参与有效性统计与超标判定
BR-10超量程处理实测值超量程上限时，以量程上限值参与统计，同时打 T 标记
BR-11负值修正SO₂ 标干浓度 > -15 mg/m³ 时修正为 0.5 mg/m³（按标准校正规则执行，可配置）
BR-12报警升级P1 报警 15 分钟未认领 → 升级至主管；30 分钟未认领 → 升级至运维单位管理员并电话通知
BR-13物资闭环运维记录中申报的试剂/备件，必须有对应出库记录，否则记录不可提交
BR-14审计不可变审计日志只允许 INSERT，禁止 UPDATE/DELETE；应用账号无该表写权限以外的任何权限
BR-15数据保留分钟数据在线保留 12 个月，之后归档；运维记录与审计日志保留 ≥3 年

9.1 验收硬指标

  • 报文解析成功率 ≥ 99.9%，未解析报文可定位原因。
  • 附录 G 判定结果与省/国发平台同一时段同一站房的差异率 ≤ 1%，且差异可逐条解释。
  • 运维记录可导出符合 HJ 355/HJ 75 台账要求的 PDF，含签名与照片。
  • 四端消息一致：同一报警在 Web、飞书、小程序中的处置状态实时同步。
  • 审计日志完整性：任意一条数据修改均可追溯到人、时间、改前值。
